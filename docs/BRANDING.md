# Splay branding

Splay is a modified local fork of MacParakeet-MC. It keeps the existing
`com.macparakeet.mc` bundle identifier and `MacParakeet-MC` application-support
namespace intentionally, so updating an existing local installation preserves
settings, recordings, transcripts, and the current macOS privacy grants.

Only the user-facing identity changes: the installed app is **Splay**, its app
icon is the supplied full Splay icon, and compact island surfaces use the
supplied three-splay mark and violet palette. Swift package/module identifiers
remain unchanged to keep builds and stored data compatible.

The fork remains subject to the repository's GPL license and attribution. The
packaged app continues to include `LICENSE` and `THIRD_PARTY_LICENSES`; neither
is renamed or removed by this branding layer.
