Seven accent themes

Derived from wind marks 2a–2f plus one added coral, packaged as user-selectable app colors in the spirit of the iMac color relaunch. Each theme is one accent family: an ink accent, a hover step, a bright dark-mode variant, and a two-stop tinted ground for cards and the island backlight. Only the accent family changes between themes — neutrals, type and geometry stay fixed.

semantic state colors (recording red, done green, warning yellow) are NOT themed — they stay constant across all six.
