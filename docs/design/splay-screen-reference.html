Splay

The single, top-centre recording island. This file is a static functional and visual baseline for implementation review—not a dashboard or a second app surface.

Identity. Near-black is the continuous surface; restrained lavender/deep violet is the primary, selection, and ready accent. The full supplied icon belongs in macOS app chrome. The compact three-splay mark is used sparingly inside the island. Red and amber stay semantic.

Lifecycle: one surface, compact forms

The idle pill is the exact same long-lived object as every expanded state. It morphs rather than presenting an overlay or window.

Idle

Top-centre, visually adjacent to the notch. No label until intent.
